# UnniA10 App Store

Dark, minimal free APK download site.

## Add your app
1. Put your APK in `apps/`.
2. Edit `index.html` and replace `Your App Name`, version, description, and `apps/your-app.apk` with your real values.
3. For another app, duplicate the `<article class="card">...</article>` block.

## Free GitHub Pages hosting
Create a public GitHub repository, upload these files, then go to Settings → Pages → Deploy from a branch → `main` → `/root` → Save.

For large APKs, use GitHub Releases and point the Download APK link to the release asset.
